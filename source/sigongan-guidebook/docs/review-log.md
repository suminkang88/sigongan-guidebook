## 발견·수정·재검증

1. 범위 표기의 `~`가 Markdown 취소선으로 해석됨: 해당 문단의 문자 참조로 수정하고 487개 원문 비교 재통과.
2. 브랜드 링크의 시각 텍스트와 aria-label 불일치: 불필요한 이름 재정의를 없애고 실제 텍스트 이름 사용. axe 재통과.
3. 모바일 검색의 텍스트가 숨겨질 때 링크 이름 누락: 항상 접근 가능한 이름 제공. 세 테마 검사 재통과.
4. 반복 요약·Do/Don’t를 동일한 이름의 랜드마크로 선언: 의미 없는 랜드마크를 제거하고 정적 div와 보이는 라벨로 수정. 9개 경로 axe 재통과.
5. 데스크톱에 모바일 목차 버튼이 보이고 장 번호가 줄바꿈됨: CSS 우선순위와 번호 flex 크기 수정. 캡처 재검토 및 48개 검사 통과.
6. Astro 개발 도구의 별도 제목이 검사를 간섭: dev toolbar 비활성화. 제품 본문 H1 하나 재확인.
7. JavaScript 비활성 안내는 기본 HTML의 텍스트로 제공하고 JS 초기화 후 숨겨, 스크립트 미실행 상태에서도 읽을 수 있게 수정.
8. 서체·빌드 도구의 홈 디렉터리 쓰기를 피하도록 npm 캐시를 작업 공간에 두고 Astro telemetry를 실행 래퍼에서 비활성화. 사용자 홈에는 직접 파일을 쓰지 않음.

- 별도 W3C HTML validator 전수 검사, 실제 사용자 과업 테스트, WA 인증 심사: **미실시**

## 후속 수정 검증 — 2026-11-23

사용자의 후속 수정 요청을 반영했습니다.

- 검색은 정규화·동의어 처리를 포함한 부분 문자열 AND 검색임을 확인했습니다. 장 제목 12·소제목 8·본문 1의 가중치를 적용하고, FAQ 질문·답변도 다른 본문과 함께 검색합니다. AI 답변 생성이나 FAQ 전용 검색으로 설명하지 않습니다. 자세한 규칙은 `search-behavior.md`에 기록했습니다.
- 헤더와 푸터의 시공간 이름 왼쪽에 32px의 빈 로고 슬롯을 확보했습니다. 의미 없는 임시 이미지나 로고 문구는 노출하지 않습니다.
- Do/Don’t 기본 테두리·아이콘·가운뎃점을 제거했습니다. 제목은 18px/700, 배경은 채도가 낮은 회색 계열로 조정했고 본문은 기본 글자색으로 읽히게 했습니다.
- 접근성 안내의 7개 이용 방법에 짧은 사용 예시를 추가했습니다. 요청하신 ‘구현 목표와 검증 범위’ 및 ‘JavaScript를 사용할 수 없을 때’ 섹션은 공개 안내 페이지에서 제거했습니다. 미실시 검증의 기록은 개발 문서에 보존합니다.
- 정적 빌드와 원문 487개 항목 대조가 통과했습니다. 전체 Playwright 48개가 통과했고, 마지막 제목 굵기·간격 조정 뒤 관련 접근성·시각 검사 19개도 재통과했습니다. 자동 axe 검사에서 선택한 규칙 위반은 0건입니다.
- 변경한 예시 부분과 모바일 320px 화면을 캡처해 직접 시각 점검했습니다. 로고 자리로 인한 페이지 전체 넘침은 없습니다.
- 관리형 프리뷰의 브라우저 릴레이는 동일한 timeout으로 연결되지 않았습니다. 같은 앱에 프로젝트의 테스트 러너를 실행했고 별도 우회 터널은 만들지 않았습니다. 확인 가능한 결과는 기존 소유자 전용 Sites 검토본에 갱신합니다.
- 사용자가 GitHub 저장소를 직접 공개로 생성했으므로 공개 선택을 유지합니다. GitHub 업로드는 별도 체크아웃에서 진행하며 `.openai`의 Sites 설정·Git 인증 정보·로컬 실행 산출물은 제외합니다. 대상은 `suminkang88/sigongan-guidebook`, Vercel은 개인 계정입니다.

## 브랜드 로고와 활용 안내 수정 — 2026-11-23
