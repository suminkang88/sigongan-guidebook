# 브랜드 로고 자산

사용자가 첨부한 참고 이미지와 같은 시공간·에이택 심벌의 공식 PNG 원본을 로컬 자산으로 포함했습니다. 로고 도형이나 색상을 임의로 다시 그리지 않았습니다.

- 시공간 심벌: https://sigongan.com/logos/sigongan.png (512 × 512, 투명 PNG)
- 에이택 심벌: https://sigongan.com/logos/aitag.png (469 × 512, 투명 PNG)
- 저장 위치: `public/images/brand/sigongan.png`, `public/images/brand/aitag.png`

시공간은 기존 이름 옆의 32px 로고 자리에 심벌을 표시합니다. 에이택은 서비스 안내 제목 옆에서 심벌과 서비스 이름을 함께 표시합니다. 좁은 화면에서는 자연스럽게 줄바꿈됩니다. 이름이 주변 텍스트에 이미 있으므로 심벌의 alt는 빈 값으로 두어 중복 낭독을 줄였습니다. 어두운 테마에서도 원본 로고가 보이도록 로고 뒤에 흰색 면을 둡니다.
