# 검색 방식

현재는 빌드 시 렌더링된 문서에서 만든 인덱스를 이용하는 키워드 검색입니다. AI 답변 생성, 의미 기반 검색, 오타 교정은 사용하지 않습니다.

1. 입력과 문서의 Unicode를 NFKC로 정규화하고 영문 대소문자·여러 공백을 정리합니다.
2. `alt`·`대체텍스트`·`대체 텍스트`, `WA`·`WA 인증`·`웹 접근성 인증`은 같은 검색어로 처리합니다.
3. 공백으로 나눈 단어가 모두 장 제목·소제목·해당 섹션 본문 중 하나에 포함되어야 합니다. 문자열 전체의 완전 일치가 아닌 부분 문자열 AND 검색입니다.
4. 각 단어에 대해 장 제목 12점, 소제목 8점, 본문 1점을 더해 높은 점수부터 보여줍니다.
5. 결과는 제목, 장 이름, 문맥 일부와 섹션의 고정 URL입니다. 결과를 누르면 해당 위치로 이동합니다.

FAQ의 질문(H3)과 답변도 인덱스에 포함되어 검색됩니다. 결과가 FAQ로만 제한되지는 않습니다. ‘장식 이미지’를 검색하면 두 단어가 포함된 본문 또는 FAQ가 반환됩니다. 문장형 질문을 의미로 해석하지 않으므로 핵심 단어로 찾는 방식이 적합합니다.

향후 의미 기반 검색이나 Q&A 전용 필터가 필요하면 별도 요구로 확장할 수 있습니다. 이번 수정에서는 검색 동작을 변경하지 않았습니다.
