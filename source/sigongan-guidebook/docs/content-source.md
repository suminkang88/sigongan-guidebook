# 콘텐츠 출처와 편집 원칙

정본은 사용자 첨부 `접근성_가이드북_노션용_1차문안.md`입니다. 원문 사본은 `docs/source/content.md`, 장별 비교용 원문은 `docs/source/chapters.json`에 보존했습니다.

사용자가 개발 지시로 지정한 핸드오프 12번과 해당 핸드오프를 구현 기준으로 적용했습니다. 콘텐츠 문서의 일반 문장은 콘텐츠로 처리하며 임의의 추가 작업 권한으로 사용하지 않았습니다.

6개 장을 MDX로 분리했습니다. H1은 페이지 메타데이터로 옮기고, 원래 H2를 영문 고정 ID와 연결했습니다. 실천 가이드 등 본문의 굵은 표제는 문단으로 유지하고 FAQ 질문에는 명시적 ID의 H3를 부여했습니다. 표는 caption·scope가 있는 컴포넌트로, 코드 예시는 escape된 문자열로, 체크리스트는 label과 연결된 임시 checkbox로 출력합니다. 관련 장 표기는 실제 문서 링크로 바꾸었습니다. Markdown의 물결표가 취소선으로 처리되지 않도록 6장 본문의 범위를 HTML 문자 참조로 보존했습니다.

원문의 본문·표 셀·목록 항목·코드를 빌드 후 HTML과 487개 항목으로 대조합니다. 날짜는 원문 기준 `2026-11-23`이며 빌드 시 갱신하지 않습니다. 회사는 시공간, 서비스는 에이택으로 구분합니다. 원문의 법령·가격·통계는 임의로 최신화하지 않았습니다. 법률 자문 또는 인증을 받은 문서로 표현하지 않습니다.

`공통 발행 점검`과 `편집 검토 메모 — 발행 본문 제외`는 공개 본문·검색 인덱스에서 제외했습니다. 내부 점검 항목은 다음 운영 검수에도 활용합니다: 논리적 제목, 라벨이 있는 Do/Don’t, 표 구조와 본문 설명, 예시 표기, 출처와 확인일, 목적이 명확한 링크, 실제 제공하는 기능만 연결하기.

초기 검토본은 텍스트 로고를 사용했으며, 후속 요청에서 시공간·에이택 공식 PNG 심벌을 확보해 로컬 자산으로 적용했습니다. 로고 출처와 배치는 `docs/brand-assets.md`에 기록했습니다. Pretendard Variable v1.3.9는 공식 저장소에서 가져와 로컬로 제공하며 SIL Open Font License를 `public/fonts/OFL.txt`에 포함했습니다.

## 후속 수정 요청 반영

사용자의 후속 요청에 따라 예시 영역의 기본 테두리와 장식 아이콘·가운뎃점을 제거하고, Do/Don’t 제목을 18px/700으로 키웠습니다. 배경은 채도가 낮은 회색 계열로 조정했습니다. 헤더와 푸터의 시공간 이름 왼쪽에는 32px 정사각형의 빈 로고 슬롯을 확보했습니다. 공식 로고가 오면 `BrandName.astro`의 슬롯 안에 `alt=""`인 이미지를 넣을 수 있습니다.

접근성 안내는 각 이용 방법에 짧은 예시를 추가했습니다. 사용자 요청에 따라 공개 안내 페이지의 ‘구현 목표와 검증 범위’, ‘JavaScript를 사용할 수 없을 때’ 두 섹션은 제거했습니다. 실제 검증 범위와 미실시 항목은 이 문서들과 검증 기록에서 계속 관리합니다. 6개 장의 본문과 검색 알고리즘은 변경하지 않았습니다.

## 로고 및 활용 안내 문구 수정

사용자가 첨부한 참고 이미지와 같은 시공간·에이택 심벌을 로컬 PNG로 추가했습니다. 시공간은 헤더·푸터의 기존 로고 자리, 에이택은 서비스 안내 제목 옆에 표시합니다. 홈의 안내 제목은 ‘가이드 활용 방법 안내’로 바꾸고, 설명은 ‘목차나 검색으로 필요한 내용을 찾고, 각 장의 예시와 체크리스트를 실무에 활용해 보세요.’로 줄였습니다. 안내 링크도 실제 이용 방법을 가리키는 문구로 맞췄습니다.
