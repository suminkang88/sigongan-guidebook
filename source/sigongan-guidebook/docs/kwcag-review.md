# KWCAG 2.2 별도 점검 기록

기록일: 2026-11-23 (KST). 33개 검사항목을 WCAG 성공 기준과 별도로 검토했습니다. 아래의 확인은 명시한 자동·코드·화면 범위이며 전체 적합성 판정이 아닙니다. 실기기 보조기술 사용성은 미실시입니다.

번호는 KS X OT0003 본문의 장절을 사용합니다. 표준 번호와 실무 요약의 1~4 원칙 번호를 혼용하지 않습니다. 참조 위치의 단순 스크롤 문서 제외 판단은 현재 구현 범위에 대한 판단입니다.

| 항목 | 검사 결과와 한계 |
| --- | --- |
| 5.1.1 적절한 대체 텍스트 제공 | 구조 확인: 장식 SVG는 숨기고 텍스트 이름 제공. 본문 HTML 예시는 문자열로 escape. 실제 정보 이미지 없음. |
| 5.2.1 자막 제공 | 해당 없음: 가이드 본문에 오디오·비디오 없음. |
| 5.3.1 표의 구성 | 자동·구조 확인: 모든 표 caption, col/row scope와 원문 설명. 실제 스크린리더 표 탐색은 미실시. |
| 5.3.2 콘텐츠의 선형구조 | 구조·키보드 확인: 제목·요약·현재 장 목차·본문·FAQ·출처·이전 다음 순서. 화면낭독 실청취 미실시. |
| 5.3.3 명확한 지시사항 제공 | 문안·구조 확인: 위치·색상에만 의존하는 지시 없음. 조작 버튼에 텍스트 이름 제공. |
| 5.4.1 색에 무관한 콘텐츠 인식 | 구조 확인: Do/Don’t 라벨, 선택 테두리·굵기, 본문 링크 밑줄 제공. |
| 5.4.2 자동 재생 금지 | 해당 없음: 자동 재생 매체 없음. |
| 5.4.3 텍스트 콘텐츠의 명도 대비 | 자동 확인: 라이트·다크·고대비 axe 검사 및 토큰 대비 계산. 실디스플레이 저시력 사용자 검증 미실시. |
| 5.4.4 콘텐츠 간의 구분 | 화면 확인: 여백·테두리·그룹명으로 구분. 320~1440px 확인. |
| 6.1.1 키보드 사용 보장 | 브라우저 자동 조작 확인: skip·목차·설정·검색·복사·체크박스·표 스크롤. |
| 6.1.2 초점 이동과 표시 | 브라우저 자동 조작·CSS 확인: 논리 순서, 3px ring, 실제 헤더 높이 offset, 메뉴 닫기 초점 복귀. |
| 6.1.3 조작 가능 | 구조·화면 확인: 주 버튼 44px 이상, 네이티브 input·label 사용. 터치 실기기 미실시. |
| 6.1.4 문자 단축키 | 해당 없음: 단일 문자 단축키 없음. |
| 6.2.1 응답시간 조절 | 해당 없음: 시간제한 없음. |
| 6.2.2 정지 기능 제공 | 해당 없음: 자동 갱신·자동 이동 콘텐츠 없음. |
| 6.3.1 깜빡임과 번쩍임 사용 제한 | 구조·화면 확인: 점멸·입장 애니메이션 없음. |
| 6.4.1 반복 영역 건너뛰기 | 브라우저 자동 조작 확인: 첫 Tab의 본문 바로가기와 main 초점 이동. |
| 6.4.2 제목 제공 | 자동·구조 확인: 고유 title, 페이지당 H1 하나, H2·FAQ H3 계층. |
| 6.4.3 적절한 링크 텍스트 | 자동·문안 확인: 장 제목·출처·서비스 이름을 링크 이름으로 제공. |
| 6.4.4 고정된 참조 위치 정보 | 해당 없음: 페이지 구분자가 있는 전자출판문서 뷰어가 아닌 연속 스크롤 문서. 장·섹션의 고정 URL은 제공. |
| 6.5.1 단일 포인터 입력 지원 | 해당 없음: 다중·경로 기반 입력 없음. 모든 조작은 click 또는 native 입력. |
| 6.5.2 포인터 입력 취소 | 코드 확인: pointerdown·mousedown 실행 없음. 표준 click·form submit 사용. |
| 6.5.3 레이블과 네임 | 자동·구조 확인: 시각적 텍스트와 접근 가능한 이름 일치. 모바일 검색 아이콘의 이름 누락 수정. |
| 6.5.4 동작기반 작동 | 해당 없음: 기기 움직임 입력 없음. |
| 7.1.1 기본 언어 표시 | 자동·구조 확인: html lang=ko, 독립 영문 표제 lang=en. |
| 7.2.1 사용자 요구에 따른 실행 | 브라우저·코드 확인: 초점만으로 이동·새 창·제출 없음. 설정 변경은 선택한 보기 설정만 반영. |
| 7.2.2 찾기 쉬운 도움 정보 | 구조 확인: 모든 페이지 푸터와 전체 목차의 동일한 위치에 접근성 안내·문의 경로. |
| 7.3.1 오류 정정 | 브라우저 확인: 검색어 보존, 결과 없음·추천 검색어·전체 목차·실패 안내. 개인정보 입력폼 없음. |
| 7.3.2 레이블 제공 | 자동·구조 확인: 검색 label, 설정 fieldset·legend·radio label, checkbox label. |
| 7.3.3 접근 가능한 인증 | 해당 없음: 가이드에 로그인·인지 테스트 없음. 호스팅 서비스의 별도 로그인 화면은 검사 범위 밖. |
| 7.3.4 반복 입력 정보 | 해당 없음: 여러 단계 입력 절차 없음. |
| 8.1.1 마크업 오류 방지 | 빌드·구조 확인: Astro/MDX 정적 생성, ID 중복 검사, 표 구조. W3C 전체 HTML validator 별도 실행은 미실시. |
| 8.2.1 웹 애플리케이션 접근성 준수 | 자동·구조 확인: native HTML, aria-expanded·aria-current·status. 실제 보조기술 이름·상태 청취 미실시. |
